# Login Page Using HTML and CSS

## Project Description

The Login Page is a responsive web interface designed using HTML and CSS. It provides users with a clean login form containing email, password, Remember Me, Forgot Password, and Sign Up options.

## Objective

The main objective of this project is to design a simple, attractive, and responsive login page using HTML and CSS.

## Technologies Used

* HTML5
* CSS3
* Responsive Web Design

## Features

* Clean and modern login interface
* Email input field
* Password input field
* Remember Me checkbox
* Forgot Password link
* Login button
* Sign Up link
* Responsive design
* Hover effects
* Mobile-friendly layout
* Required-field validation through HTML

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html`.
4. The Login Page will open in your web browser.

You can also open `index.html` using Visual Studio Code with the Live Server extension.
